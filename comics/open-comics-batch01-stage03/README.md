# Open Comics Batch 01 — Stage 03

Последний канонический завершённый пакет. Stage01 и другие промежуточные версии отдельно не публикуются.

В пакет входят 6 импортируемых языковых версий трёх произведений:
1. Acelera SP V01 — PT-BR
2. Ускоряйся SP V01 — RU
3. Cosmogonias V01 — PT-BR
4. Космогонии V01 — RU
5. Silent Ruin V01 — EN
6. Безмолвная Руина V01 — RU

Для каждого элемента обязательны:
- `book.cbz` — реальные страницы комикса;
- `cover.jpg` — реальная обложка;
- `description.txt`;
- `metadata.json`;
- `LICENSE.txt`;
- контрольная запись импорта.

Пакет нельзя считать готовым к импорту при отсутствии CBZ, обложки или лицензии.
