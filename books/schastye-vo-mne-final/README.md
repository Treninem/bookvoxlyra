# Счастье во мне

Канонический завершённый пакет VoxLyra.

Ожидаемый полный состав пакета:
- `book.fb2` — полный текст, 170 глав;
- `cover.jpg` — обложка;
- `description.txt` — описание;
- `metadata.json` — метаданные;
- `books_import.json` — запись импорта;
- `manifest.json` — контроль целостности.

Пакет нельзя считать готовым к импорту, если отсутствует `book.fb2` или `cover.jpg`.
