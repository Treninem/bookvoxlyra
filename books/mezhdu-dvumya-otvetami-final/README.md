# Между двумя ответами

Канонический завершённый пакет VoxLyra.

Полный состав:
- `book.fb2` — полный текст, 1020 глав;
- `cover.jpg` — обложка;
- `description.txt` — описание;
- `metadata.json` — метаданные;
- `books_import.json` — запись импорта;
- `manifest.json` — контроль целостности.

Импорт разрешается только при физическом наличии полного текста и обложки.
