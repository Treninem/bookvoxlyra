# BookVoxLyra

Source-only repository for owner-controlled content import into VoxLyra.

## Главное правило

Готовый контент ведётся **не как файлы для выдачи в чате**, а напрямую в этом репозитории. Чат используется только как рабочая среда; канонический результат должен оказаться в `Treninem/bookvoxlyra`.

VoxLyra не использует этот репозиторий как БД или постоянное runtime-хранилище. Она выборочно скачивает проверенный пакет, передаёт его существующему импортёру и после импорта работает с обычной БД/хранилищем VoxLyra.

## Структура

- `books/<package_id>/` — книги;
- `comics/<package_id>/` — комиксы/манга/манхва/вебтуны;
- `audiobooks/<package_id>/` — аудиокниги;
- `manifests/import_index.json` — единственный индекс обнаружения пакетов;
- `tools/validate_packages.py` — проверка структуры, SHA-256, evidence и payload.

Пакет получает `enabled=true` только после того, как в репозитории физически присутствуют его точные канонические payload-файлы, финальная обложка, `LICENSE.txt`, `SOURCES.txt` и актуальный manifest. Валидатор запрещает небезопасные пути, несовпадение SHA-256, пустые evidence-файлы, отсутствие настоящего произведения, undeclared payload и дубли включённых package ID/path.

## Правило версий произведений

Одно произведение хранится один раз под последним каноническим названием и последней завершённой редакцией. Переименование не создаёт новую книгу. Старые обложки, старые названия, промежуточные архивы, черновики и superseded revisions не становятся отдельными импортируемыми произведениями.

## Автопроверка

`.github/workflows/validate-packages.yml` запускает `python3 tools/validate_packages.py`. Отдельные fixture-тесты проверяют corrupt hashes, неверный `enabled`, отсутствующие/пустые rights-файлы и undeclared payload. Репозиторий остаётся валидным даже при нуле включённых пакетов; незавершённый пакет не включается только ради видимости результата.
